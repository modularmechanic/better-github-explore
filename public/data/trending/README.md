# Trending snapshots

Generated by `npm run sync:trending`, refreshed daily by `.github/workflows/sync-data.yml`.
Do not edit by hand — the next sync overwrites them.

These mirror github.com/trending exactly, which means two things look like bugs and are not:

**A repository's `language` may not match the file it is in.** `github.com/trending/{language}`
is not a filter on a repository's primary language. `microsoft/TypeScript` genuinely appears on
the live weekly Go page, verified against github.com. Filtering those rows out would make the
snapshot disagree with the page it exists to mirror.

**`starsInPeriod` is the number these pages rank by**, and no public API exposes it. That is the
whole reason for scraping rather than querying `/search/repositories`.
